# Adaptive Modulation and Coding (AMC) using GNU Radio

Project demonstrating dynamic switching between **BPSK**, **QPSK**, and **QAM** modulation schemes based on channel conditions using GNU Radio Companion.

## Repository Structure
* `Adaptive Modulation Coding/` - Main project folder containing flowgraphs, Python scripts, and reports.

## Key Features
* **Adaptive Modulation:** Dynamic modulation scheme transition based on SNR.
* **SDR Architecture:** Built using GNU Radio Companion and custom Python blocks.
* **Real-Time Visualization:** Constellation diagrams, spectrum analysis, and BER monitoring.
